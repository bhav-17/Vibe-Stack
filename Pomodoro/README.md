# 🍅 FocusFlow — Pomodoro Timer & Task List

**Focus better. Work smarter. Get things done.**

FocusFlow is a simple, modern productivity web app that combines a Pomodoro timer with a daily task checklist. It helps you break your work into focused sessions, organize your daily goals, and track your progress throughout the day.

## ✨ Features

* ⏱️ **Pomodoro Timer** — A 25-minute countdown designed for focused work sessions.
* ▶️ **Timer Controls** — Start, pause, and reset your timer whenever you need.
* ✅ **Daily Task List** — Add tasks, mark them as completed, and delete them when they're no longer needed.
* 🎯 **Task Priorities** — Organize your goals by High, Medium, and Low priority.
* 🍅 **Focus Session Goals** — Set the number of Pomodoro sessions required for each task.
* 📊 **Progress Tracking** — Visual progress bars help you see how much you've accomplished.
* 💾 **Local Storage** — Your tasks remain saved in your browser between visits.
* 📱 **Responsive Design** — A clean interface that adapts to desktop, tablet, and mobile screens.
* 🌙 **Dark UI** — A distraction-free dark interface with subtle styling and animations.

```bash

```

### 2. Open the project folder

```bash

```

### 3. Run the application

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a smoother development experience.

## 📖 How to Use

1. **Start focusing:** Click Start to begin a 25-minute Pomodoro session.
2. **Manage your timer:** Pause or reset the countdown whenever needed.
3. **Add a daily goal:** Enter a task in the task input field.
4. **Set a priority:** Choose High, Medium, or Low based on the task's importance.
5. **Set focus sessions:** Select how many 25-minute sessions you want to dedicate to the task.
6. **Track your progress:** Check off completed tasks and monitor your daily progress.

### 🍅 What Is a Focus Session?

One focus session represents **25 minutes of dedicated work**. For example, if a task requires two sessions, the goal is to spend approximately 50 minutes working on it, excluding breaks.
